# Jokes App

Jokes App is a web application that displays jokes along with their answers. Built with .NET and C#, it utilizes the Model-View-Controller (MVC) design pattern for a clean separation of concerns, and it leverages Entity Framework for database configuration. With a modern UI powered by Bootstrap and custom CSS, this app offers an engaging experience for users looking to enjoy and manage jokes.

## Features

- **Joke Display:** View a curated list of jokes with their answers.
- **Search Functionality:** Quickly filter jokes by keywords.
- **User Authentication:** Secure login system is required to create, edit, or delete jokes.
- **CRUD Operations:** Authenticated users can add new jokes, update existing ones, or remove jokes.
- **MVC Architecture:** Organized code structure separating Models, Views, and Controllers.
- **Entity Framework:** Simplified database configuration and migrations.
- **Responsive Design:** Built using Bootstrap classes and ASP.NET CSS for a sleek and responsive interface.

## Technologies Used

- **.NET & C#:** Core technologies powering the application.
- **ASP.NET MVC:** Implements the Model-View-Controller pattern.
- **Entity Framework:** Manages database interactions and schema.
- **Bootstrap:** Provides responsive, mobile-first design components.
- **CSS:** Custom styling to complement the Bootstrap framework.
